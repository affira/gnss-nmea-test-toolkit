order and verbatim. Short replies are kept as typed, including typos. The assistant's
replies are not included.

1. [01-plan-and-data.md](01-plan-and-data.md): project goal, working rules, data sourcing and the plan
2. [02-approvals.md](02-approvals.md): one-line approvals between steps 0 to 5
3. [03-thresholds-and-profiles.md](03-thresholds-and-profiles.md): report thresholds and YAML test profiles (step 6)
4. [04-readme-and-privacy-check.md](04-readme-and-privacy-check.md): this README, the prompts folder and a privacy check
5. [05-licence-author-and-ci.md](05-licence-author-and-ci.md): licence, commit author and CI (step 8)
